# 2024 決賽 P3 聊天對話框：測試說明

三個頁面：`/` 對話頁（team021.html）、`/login` 管理員登入（login.html）、`/admin` 問答管理（admin.html）。
管理員帳號 `admin`，密碼 `password`（資料庫 `admins` 資料表，存 `password_hash()` 雜湊）。

## 方式一：XAMPP（Apache）
1. 把整個資料夾放進 `C:\xampp\htdocs\`（例如 `chat\`），啟動 Apache（需啟用 mod_rewrite，XAMPP 預設已啟用）與 MySQL。
2. phpMyAdmin 匯入 `team021.sql`（建立 `chat` 資料庫、管理員、四筆預設問答）。
3. 開啟 http://localhost/chat/、http://localhost/chat/login、http://localhost/chat/admin。
   `/login`、`/admin` 由 `.htaccess` 改寫到 login.html、admin.html（若網站放在子資料夾，`.htaccess` 要和 html 放同一層）。

## 方式二：PHP 內建伺服器
在此資料夾執行 `php -S 127.0.0.1:8000 router.php`，開啟 http://127.0.0.1:8000/、/login、/admin。
`router.php` 做和 `.htaccess` 一樣的路徑對應。

連線設定：127.0.0.1、root、空密碼、預設埠（api.php 上方）。

## JWT
- `api.php` 用 `hash_hmac('sha256')` 手寫 HS256；登入成功回傳 token 與 `exp`（現在 + 600 秒）。
- 前端把 token 存在 localStorage，呼叫 API 時放 `Authorization: Bearer`；後端驗簽章與 `exp`，失敗回 401。
- 前端用 `setTimeout` 在 `exp` 到期時自動回 `/login`；沒有登出鈕。
- 未登入前往 `/admin`，或 API 回 401，都會跳回 `/login`；已登入前往 `/login` 會跳到 `/admin`。
