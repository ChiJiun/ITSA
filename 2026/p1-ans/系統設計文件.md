# 叫號與候位系統：系統設計文件（team123）

啟動：`npm start`，開啟 http://localhost:3000 。需要 Node 22.13 以上（使用內建 `node:sqlite`，啟動時的 ExperimentalWarning 可忽略）與 express。
繳交前：把 `P1_Node離線套件.zip` 裡的 `node_modules` 放進本資料夾一起壓縮，評審才能直接 `npm start`。
櫃台帳密：admin / password123

## API 一覽表

| 方法 | 路徑 | 需登入 | 主要回應 |
|---|---|---|---|
| GET | /api/state | 否 | 200 `{ current, waiting[], history[] }` |
| POST | /api/tickets | 否 | 201 `{ number, service, createdAt }`；service 非 G/A/C 或中文名稱 → 400 |
| POST | /api/login | 否 | 200 + Set-Cookie(sid)；失敗 401 |
| POST | /api/logout | 是 | 204，伺服器端刪除 session；未登入 401 |
| POST | /api/admin/next | 是 | 200 `{ current }`；已有服務中或無等待者 → 409；未登入 401 |
| POST | /api/admin/complete | 是 | 200；無服務中號碼 → 409；未登入 401 |
| GET | /api/admin/history | 是 | 200 `[ … ]`（完成時間新→舊）；未登入 401 |

## 資料表結構（queue.db）

| 資料表 | 欄位 | 型別 | 說明 |
|---|---|---|---|
| counters | prefix | TEXT PK | G / A / C |
| | n | INTEGER | 該類別目前最後號碼，不重置 |
| tickets | id | INTEGER PK AUTOINCREMENT | 取號先後 |
| | number | TEXT UNIQUE | 例 A001、C1000 |
| | service | TEXT | G / A / C |
| | status | TEXT | waiting → serving → completed |
| | created_at / called_at / finished_at | INTEGER | 毫秒時間戳，顯示時轉 YYYY/M/D HH:mm:ss |

索引：`idx_status (status, created_at)`，加速「等待中且最早」的查詢。
