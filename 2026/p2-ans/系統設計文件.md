# GamerHub：系統設計文件（team123）

環境：XAMPP（Apache + PHP + MySQL）。先在 phpMyAdmin 匯入 `gamershub.sql`，再開 http://localhost/…/p2-ans/team123.html
測試帳號：faker / caps / tenz / s1mple，密碼皆 1234

| 檔案 | 用途 |
|---|---|
| team123.html | 單頁畫面：登入、喜愛清單、發布公告、大廳、行事曆 |
| app.js | jQuery：呼叫 API、畫畫面、頁籤切換、淡出動畫 |
| api.php | 後端 API（PDO），未登入一律擋下 |
| css/all.min.css + webfonts/ | Font Awesome（CSS 內寫 ../webfonts，所以放 css/ 子資料夾） |

## API（api.php?a=…，全部用 POST）

| a | 參數 | 說明 |
|---|---|---|
| login | username, password | 成功寫入 session；失敗 401 |
| logout | | 銷毀 session |
| data | | 回傳 me、favs、anns（未滿員）、cal（已成局/滿員且我有參加） |
| addfav | name | 遊戲不存在先 INSERT IGNORE 進 games，再加入 user_games |
| delfav | game_id | 移除喜愛遊戲 |
| post | game_id, event_time, min, max | 新增公告，隊長同時寫入參與者 |
| join | id | 加入後重算狀態，回傳 open / formed / full；已滿員 409 |

未登入：AJAX 回 401（前端切回登入畫面）；瀏覽器直接開網址 → 302 跳回 team123.html。
狀態規則：人數 ≥ max → full；人數 ≥ min → formed；其他 → open。
